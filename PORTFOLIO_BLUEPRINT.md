# Portfolio blueprint - The Systems Index

## Purpose

Position Akabir Abbas through real systems work: desktop operations software, AI/ML tooling, data workflows, and carefully engineered web products. The site is a readable public index, not a product-card template.

## Direction

- **Audience:** technical collaborators, hiring managers, and founders evaluating craft and range.
- **Visual lane:** systems-lab / technical. A cool paper ground, sharp typographic hierarchy, and cobalt signal language make the work legible without relying on generic developer-site tropes.
- **Creative seed:** a project-index spatial map with twelve project points. It represents the work set rather than acting as generic 3D decoration.
- **Typography:** Manrope across display and reading copy, with native mono for project metadata. The system deliberately avoids an editorial serif so the portfolio reads as engineering-first.
- **Tokens:** paper `#f3f0e8`, ink `#172033`, cobalt `#2349b6`, vermilion `#c75035`, with role-based CSS variables in `src/app/globals.css`.
- **Motion:** an identity reveal, a slow 3D constellation rotation, pointer parallax, and CSS scroll-driven shifts that give the opening and work index continuity. All have a reduced-motion fallback.
- **3D decision:** the hero's verified twelve-project index now uses a lightweight React Three Fiber constellation. It has no models, textures, physics, shadows, or post-processing; the DOM index remains canonical.

## Information architecture

1. Introduction and signal map
2. Selected systems: four deeper project narratives
3. Complete project index: all twelve verified repositories
4. Ways of working: technical capabilities framed as outcomes
5. Closing contact path to GitHub

## Private work policy

Private repositories are represented only by their owner-approved title and high-level README information. They never receive a public repository link, code excerpt, customer data, or internal screenshot.
